## Общие заголовки (General Headers)
Применяются как к запросам, так и к ответам, но не относятся к самим данным (телу сообщения). Они управляют процессом передачи.

| Заголовок       | Пояснение                                                                                                                           |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `Upgrade`       | Необходим, для переключения на другие протоколы                                                                                     |
| `Host`          | К какому сайту обращается клиент                                                                                                    |
| `Cache-Control` | Управляет кэшированием (например, `no-cache`, `max-age=3600`). Указывает, как и где можно кэшировать ответ.                         |
| `Connection`    | Управляет сетевым соединением. Значение `keep-alive` указывает, что соединение должно оставаться открытым для последующих запросов. |
| `Date`          | Дата и время создания сообщения в формате GMT (стандарт RFC 7231).                                                                  |


## Заголовки запроса (Request Headers)
Содержат дополнительную информацию о запрашиваемом ресурсе или о самом клиенте (браузере, приложении).

| Заголовок         | Пояснение                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `Accept`          | Сообщает серверу, какие типы контента (MIME-типы) клиент способен обработать (например, `application/json`, `text/html`). |
| `Authorization`   | Содержит учетные данные для аутентификации клиента на сервере (например, `Bearer <token>` или `Basic <credentials>`).     |
| `User-Agent`      | Строка, идентифицирующая клиентское приложение: браузер, его версию, операционную систему и устройство.                   |
| `Cookie`          | Содержит ранее сохраненные сервером HTTP-куки, которые клиент отправляет обратно при последующих запросах.                |
| `Referer`         | URL-адрес предыдущей веб-страницы, с которой клиент перешел на запрашиваемую страницу.                                    |
| `Accept-Encoding` | Указывает, какие алгоритмы сжатия понимает клиент (например, `gzip`, `deflate`, `br`).                                    |

## Заголовки ответа (Response)
Содержат дополнительную информацию об ответе: о сервере, о месте нахождения ресурса или о правилах его использования.

| Заголовок          | Пояснение                                                                                                                                      |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `Set-Cookie`       | Инструкция браузеру сохранить полученные куки для последующей отправки на этот же домен.                                                       |
| `Location`         | Используется при перенаправлении (статусы 3xx) для указания нового URL, или при создании ресурса (статус 201 Created) для указания его адреса. |
| `Server`           | Содержит информацию о программном обеспечении, обработавшем запрос (например, `nginx/1.24.0`).                                                 |
| `WWW-Authenticate` | Указывает метод аутентификации, который сервер ожидает от клиента (используется вместе со статусом 401 Unauthorized).                          |

## Заголовки представления / сущности (Representation)
Описывают содержимое тела сообщения (body): его тип, размер, кодировку, язык.

| Заголовок          | Пояснение                                                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `Content-Type`     | Указывает MIME-тип данных в теле сообщения (например, `application/json; charset=utf-8`). Критически важен для корректной обработки данных. |
| `Content-Length`   | Размер тела сообщения в байтах. Позволяет клиенту понять, когда получение данных завершено.                                                 |
| `Content-Encoding` | Указывает, какой алгоритм сжатия был применен к телу сообщения (например, `gzip` или `br`).                                                 |
| `Last-Modified`    | Дата и время последней модификации ресурса на сервере. Используется для условных запросов и кэширования.                                    |

## Заголовки безопасности (Security)
Современная выделенная категория, управляющая политиками безопасности браузера для защиты от распространенных атак (XSS, clickjacking и др.).

| Заголовок                          | Пояснение                                                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Strict-Transport-Security` (HSTS) | Принуждает браузер взаимодействовать с сайтом только по защищенному протоколу HTTPS.                                                              |
| `Content-Security-Policy` (CSP)    | Определяет доверенные источники контента (скрипты, стили, изображения), защищая от XSS-атак и инъекций данных.                                    |
| `X-Frame-Options`                  | Запрещает или разрешает отображение страницы внутри `<frame>` или `<iframe>`, защищая от атак типа clickjacking (значения: `DENY`, `SAMEORIGIN`). |
| `X-Content-Type-Options`           | Запрещает браузеру "угадывать" MIME-тип (значение `nosniff`), заставляя его строго следовать заголовку `Content-Type`.                            |
