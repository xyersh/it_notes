### 1. Базовые сущности и окружение

- **Shell (Оболочка)** — программа, которая выступает посредником между пользователем и ядром операционной системы. Bash (Bourne Again SHell) — это одна из таких оболочек.
- **Команда (Command)** — то, что вы вводите. Командой может быть:
    - _Встроенная команда (Built-in):_ часть самого bash (например, `cd`, `echo`, `alias`).
    - _Внешняя утилита (External binary):_ отдельная программа в системе (например, `ls`, `grep`, `tar`).
    - _Функция или псевдоним (Alias):_ заданные пользователем сокращения.
- **Переменная окружения (Environment Variable)** — переменная, которая передается всем дочерним процессам. Чтобы сделать локальную переменную переменной окружения, используют команду `export` (например, `export PATH`).
- **Shebang (Шебанг)** — последовательность `#!` в самом начале скрипта. Указывает ОС, какой интерпретатор использовать для выполнения файла (например, `#!/bin/bash` или `#!/usr/bin/env python3`).

### 2. Потоки данных и Перенаправления (Streams & Redirection)

В Linux всё есть файл, и у каждой запущенной команды есть 3 стандартных потока:

- **STDIN (Standard Input, поток 0)** — стандартный ввод (обычно клавиатура).
- **STDOUT (Standard Output, поток 1)** — стандартный вывод (обычно экран).
- **STDERR (Standard Error, поток 2)** — поток ошибок (тоже экран, но отделен от STDOUT).

**Связанные понятия:**

- **Перенаправление (Redirection)** — изменение направления потоков.
    - `>` — перезаписать STDOUT в файл.
    - `>>` — дописать в конец файла.
    - `<` — подать файл на STDIN.
    - `2>` — перенаправить STDERR в файл.
- **Конвейер / Пайп (Pipeline / Pipe)** — символ `|`. Позволяет передать STDOUT одной команды напрямую на STDIN другой. _Пример: `cat file.txt | grep "error"`._

### 3. Аргументы и Опции

- **Позиционные параметры (Аргументы)** — данные, которые передаются скрипту или функции при запуске. Обозначаются как `$1`, `$2`, `$3` и т.д.
- **Опция / Флаг (Option / Flag)** — параметр, который меняет поведение команды. Обычно начинается с дефиса.
    - _Короткие:_ `-l`, `-a` (можно объединять: `-la`).
    - _Длинные:_ `--help`, `--verbose`.
- **Специальные переменные:**
    - `$0` — имя самого скрипта.
    - `$#` — количество переданных аргументов.
    - `$@` и `$*` — список всех переданных аргументов.
    - `$$` — PID (идентификатор) текущего процесса.

### 4. Расширения и Подстановки (Expansions)

Это процесс, при котором Bash заменяет специальные конструкции на их реальные значения _перед_ выполнением команды.

- **Расширение переменных (Variable Expansion)** — `$VAR` или `${VAR}`. Позволяет использовать значения. Также есть модификаторы, например `${VAR:-default}` (вернет "default", если VAR пуста).
- **Подстановка команд (Command Substitution)** — `$(command)`. Запускает команду и подставляет её _вывод_ (STDOUT) вместо самой конструкции.
- **Арифметическое расширение (Arithmetic Expansion)** — `$(( expression ))`. Позволяет считать математику внутри bash. _Пример: `echo $(( 5 + 3 ))` выведет 8._
- **Глоббинг / Расширение путей (Globbing / Pathname Expansion)** — использование символов-заменителей (wildcards) для поиска файлов:
    - `*` — любое количество любых символов.
    - `?` — ровно один любой символ.
    - `[abc]` — один символ из списка.


### 5. Выполнение и Управление процессами

- **Код возврата (Exit Code / Return Status)** — число от 0 до 255, которое команда возвращает после завершения.
    - **`0` означает УСПЕХ** (это часто путают новички!).
    - **`1-255` означает ОШИБКУ**.
    - Код возврата последней выполненной команды всегда хранится в переменной `$?`.
- **Подоболочка (Subshell)** — дочерний процесс, созданный bash. Изменения внутри подоболочки (например, смена директории или создание переменной) _не влияют_ на родительскую оболочку. Создается круглыми скобками: `(cd /tmp; echo "внутри")`.
- **Группа команд (Command Group)** — выполняет команды в _текущей_ оболочке (без создания дочернего процесса). Создается фигурными скобками: `{ cd /tmp; echo "внутри"; }` (обратите внимание на пробелы после `{` и точку с запятой `;` в конце).
- **Фоновый режим (Background)** — запуск задачи с символом `&` в конце (например, `sleep 100 &`). Команда выполняется в фоне, не блокируя ввод в терминале.

### 6. Кавычки и Экранирование

Понимание кавычек — это 50% успеха в Bash.

- **Двойные кавычки (`" "`)** — _слабое экранирование_. Переменные (`$VAR`) и подстановки команд (`$()`) внутри них **раскрываются** (вычисляются). Пробелы сохраняются как часть строки.
- **Одинарные кавычки (`' '`)** — _сильное экранирование_. Внутри них **всё является просто текстом**. Никакие переменные не раскроются.
- **Обратные кавычки (`` ` ` ``)** — устаревший синтаксис для подстановки команд. В современном bash рекомендуется использовать только `$(...)`.
- **Экранирование (Escaping)** — использование обратного слэша `\` для того, чтобы лишить специальный символ его магического смысла. _Пример: `echo "Цена: \$10"` выведет `$10`, а не попытается найти переменную `10`._

### 7. Специфический синтаксис ввода

- **Heredoc (Здесь-документ)** — способ передать многострочный текст на STDIN команды. Задается через `<<` и ограничитель (часто `EOF`).
```bash
cat << EOF
Это первая строка.
Это вторая строка. Переменная $USER тоже раскроется.
EOF
```

- **Herestring (Здесь-строка)** — упрощенная версия Heredoc для передачи одной строки. Задается через `<<<`. _Пример: `grep "error" <<< "this is an error line"`._
