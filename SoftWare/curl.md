
## БАЗА

**`curl`** (Client URL) — это мощный инструмент командной строки и библиотека для передачи данных с использованием различных сетевых протоколов.

**Основное назначение:** Автоматизация сетевых запросов, тестирование API, отладка сетевых соединений, скачивание и загрузка файлов без использования графического интерфейса.


**Ключевые возможности:**

- **Поддержка множества протоколов:** HTTP, HTTPS, FTP, FTPS, SCP, SFTP, IMAP, SMTP, LDAP и других.
- **Тестирование REST API:** Эмуляция любых HTTP-методов (GET, POST, PUT, DELETE, PATCH).
- **Управление заголовками и телом запроса:** Отправка JSON, XML, form-data, установка кастомных заголовков и cookies.
- **Анализ ответов:** Просмотр HTTP-заголовков, кодов состояния, времени отклика.
- **Работа с файлами:** Скачивание файлов с сохранением под заданным именем или с исходным именем сервера, а также загрузка файлов на сервер.
- **Безопасность и аутентификация:** Поддержка SSL/TLS, базовой, digest и NTLM аутентификации.


## Установка утилиты

### Для Linux

В большинстве дистрибутивов Linux `curl` уже установлен по умолчанию. Если его нет, используйте менеджер пакетов вашего дистрибутива:

- **Debian / Ubuntu / Linux Mint:**
```bash
sudo apt update
sudo apt install curl
```

- **CentOS / RHEL / Fedora:**
```bash
sudo dnf install curl
# или для старых версий: sudo yum install curl
```

- **Arch Linux / Manjaro:**
```bash
sudo pacman -S curl
```

### Windows

- **Windows 10 и 11:** `curl` уже встроен в систему (начиная с сборки 1803).
    - _Важное примечание:_ В PowerShell команда `curl` является псевдонимом (alias) для `Invoke-WebRequest`. Чтобы вызвать именно классический curl, используйте **`curl.exe`**.
- **Установка через менеджеры пакетов (если нужна последняя версия или вы на старой ОС):**
    - **Chocolatey:** `choco install curl`
    - **Scoop:** `scoop install curl`
    - **Winget:** `winget install cURL.cURL`

## Справочник основных атрибутов (ключей)

|Атрибут|Полная форма|Краткое описание|
|---|---|---|
|`-X`|`--request`|Указывает метод запроса (GET, POST, PUT, DELETE и т.д.).|
|`-H`|`--header`|Добавляет пользовательский заголовок HTTP-запроса (например, `Content-Type`).|
|`-d`|`--data`|Передает данные в теле запроса (автоматически применяет `Content-Type: application/x-www-form-urlencoded`).|
|`-o`|`--output`|Сохраняет результат выполнения в указанный локальный файл.|
|`-O`|`--remote-name`|Сохраняет файл, используя имя файла из URL.|
|`-I`|`--head`|Получает только заголовки HTTP-ответа (использует метод HEAD).|
|`-L`|`--location`|Заставляет curl следовать за редиректами (коды ответа 3xx).|
|`-v`|`--verbose`|Подробный вывод (показывает заголовки запроса, ответа и процесс соединения).|
|`-s`|`--silent`|Тихий режим (скрывает прогресс-бар и ошибки).|
|`-S`|`--show-error`|Показывает ошибки, если используется в связке с `-s`.|
|`-u`|`--user`|Указывает логин и пароль для серверной аутентификации (формат `user:password`).|
|`-k`|`--insecure`|Игнорирует проверку подлинности SSL-сертификатов (использовать только для тестов!).|
|`-F`|`--form`|Отправляет данные как `multipart/form-data` (используется для загрузки файлов).|
|`-w`|`--write-out`|Выводит указанную информацию после завершения запроса (коды, время, размер).|

## Примеры использования (от базовых к продвинутым)

### Базовый уровень

- **Простой GET-запрос (получение содержимого страницы)**
```bash
curl https://example.com
```

- **Скачивание файла с сохранением под заданным именем**
```bash
curl -o logo.png https://example.com/images/logo.png
```

- **Скачивание файла с сохранением исходного имени**
```bash
curl -O https://example.com/files/archive.zip
```

### Средний уровень

- **Просмотр только HTTP-заголовков (проверка статуса сайта или типа контента)**
```bash
curl -I https://example.com
```

- **Отправка POST-запроса с JSON-данными (Тестирование API)**
```bash
curl -X POST https://api.example.com/users \
     -H "Content-Type: application/json" \
     -d '{"name": "Иван", "age": 30}'
```

- **Следование за редиректами (если короткая ссылка ведет на другой домен)**
```bash
curl -L https://bit.ly/some-short-link
```

- **Тихий режим с отображением ошибок (удобно для скриптов)**
```bash
curl -sS https://api.example.com/data
```

### Продвинутый уровень

- **Загрузка файла на сервер (Multipart form-data)**
```bash
curl -X POST https://upload.example.com/api \
     -F "avatar=@/path/to/local/photo.jpg" \
     -F "user_id=12345"
```
> (Символ `@` перед путем к файлу обязателен, он указывает curl, что нужно прочитать локальный файл).

- **Базовая HTTP-аутентификация**
```bash
curl -u admin:secretpassword https://secure.example.com/admin/dashboard
```

- **Отладка SSL-соединения (игнорирование самоподписанных сертификатов)**
```bash
curl -v -k https://dev.local.api
```

- **Форматированный вывод статистики (Измерение времени отклика и кода ответа)** Используется для мониторинга доступности API. Прогресс и тело ответа скрываются, выводится только нужная метрика.
```bash
curl -s -o /dev/null -w "HTTP Status: %{http_code}\nTotal Time: %{time_total} sec\nDownload Size: %{size_download} bytes\n" https://example.com
```

**Использование переменных окружения и чтение данных из файла** Если JSON слишком большой, его можно прочитать из файла, используя `@`:
```bash
curl -X POST https://api.example.com/bulk \
     -H "Authorization: Bearer $MY_API_TOKEN" \
     -H "Content-Type: application/json" \
     -d @large_payload.json
```
