
## Уровни наcтроек
- **Системные** - Это настройки **для всех пользователей** на данном компьютере.
- **Глобальные** - это настройки конкретного пользователя  внутри данной машины
- **Локальные** - Это настройки **для конкретного репозитория**. Они применяются только тогда, когда мы находимся внутри этой папки с проектом.

> Главное правило Git: **чем «ближе» настройка к конкретному репозиторию, тем выше её приоритет**. Локальные настройки перекрывают глобальные, а глобальные перекрывают системные.
## Расположение файлов с настройками

### Системные
- `C:\Program Files\Git\etc\gitconfig` ИЛИ `mingw64\etc\gitconfig` - в Win
- `/etc/gitconfig` - в Linux

### Глобальные

- `C:\Users\<User Name>\.gitconfig` - в Win
- `~/.gitconfig` или `~/.config/git/config` - в Linux

### Локальные
- `.git/config` - в локальном файле проекта, на всех ОС


## Команды
- `git config --global --list` - просмотр глобальных настроек
- `git config --global user.email` - просмотр конкретной глобальной настройки (user.email)
- `git config --global --list --show-origin` - просмотр глобальных настроек + указывает файл из которого они читаются
- `git config --global --unset <ключ>` - удалить последнее значение конкретной глобальной настройки по ключу
- `git config --global --unset-all <ключ>` - удалить все значения конкретной глобальной настройки по ключу
- `git config --global --remove-section alias` - удалить всю секцию по ключу **alias**
- `git config --list --show-origin` - просмотреть ВСЕ настройки с учетом их иерархии.

для системных и локальных настроек - та же логика, только вместо `--global` используем `--system`, `--local` соответственно.
