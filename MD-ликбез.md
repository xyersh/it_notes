В **Markdown** параграфы (**Paragraphs**) создаются с помощью **пустой строки**, которая отделяет один блок текста от другого.

```html

```


### СТИЛИ ТЕКСТА

#### Жирный текст
- **Жирный текст:** `**жирный текст**` или `__жирный текст__`
- __Тоже жирный текст__
- Аналог HTML: `<strong>JavaScript</strong>`



#### Курсив
- *Курсивный текст:* `*курсивный текст*` или `_курсивный текст_`
- ***Курсивный жирный текст:*** This is really***very***important text
- Аналог HTML:  `<em>JavaScript</em>`

#### Зачеркнутый текст
- ~~Зачеркнутый текст~~: `~~зачеркнутый текст~~`
- Аналог HTML: `<s>var</s>`

#### Маркер
- ==Подсвеченный текст==: `==подсвеченный текст==`

#### Цвет текста
**Markdown** не позволяет изменять цвет текста напрямую. Для этого придется использовать HTML
```markdown
<font color="red">Ошибка в JavaScript коде</font>
```
<font color="red">Ошибка в JavaScript коде</font>

```markdown
<span style="color:red">Ошибка в JavaScript коде</span>
```
<span style="color:red">Ошибка в Python коде</span>


#### Нижний индекс
**Нижний индекс (Subscript****)** в **Markdown** — это нечасто используемая, но иногда полезная функция, которая позволяет понизить позицию одного или нескольких символов ниже обычной линии текста.
```markdown
H~2~O: Вода
```
Аналог HTML:
```html
H<sub>2</sub>O: Вода
```

H<sub>2</sub>O: Вода


#### Верхний индекс
**Верхний индекс** в **Markdown** — это нечасто используемая, но иногда полезная функция, которая позволяет поднимать один или несколько символов выше обычной линии текста.
```markdown
E=mc^2^: Формула относительности Эйнштейна
```
Аналог HTML:
```html
E=mc<sup>2</sup>: Формула относительности Эйнштейна
```

E=mc<sup>2</sup>: Формула относительности Эйнштейна


### ЭКРАНИРУЮЩИЕ СИМВОЛЫ^123
В **Markdown** иногда нужно показать символы, которые обычно используются для форматирования текста. Например, звездочку `*`, подчеркивание `_` или решетку `#`.
Чтобы такие символы отображались как обычный текст, используется **экранирование (escaping characters)**. Для этого перед символом ставится обратный слеш `\`.

```markdown
Используйте функцию \*calculateTotal\* для вычисления суммы
```

#### Таблица символов которые можно экранировать
|     |                                         |
| --- | --------------------------------------- |
| \   | обратный слеш (backslash)               |
| `   | обратная кавычка (backtick)             |
| *   | звездочка (asterisk)                    |
| _   | подчеркивание (underscore)              |
| { } | фигурные скобки (curly braces)          |
| [ ] | квадратные скобки (brackets)            |
| < > | угловые скобки (angle brackets)         |
| ( ) | круглые скобки (parentheses)            |
| #   | знак номера (pound sign)                |
| +   | плюс (plus sign)                        |
| -   | минус (minus sign, hyphen)              |
| .   | точка (dot)                             |
| !   | восклицательный знак (exclamation mark) |
| \|  | вертикальная черта (pipe)               |

- **Цитаты:**  `> содержимое цитаты`

### ТАБЛИЦЫ
ля создания таблицы в **Markdown** используются вертикальные черты `|` для разделения ячеек и тире `-` (минуса) для разделения заголовков и строк таблицы.
**Markdown** позволяет выравнивать текст в ячейках таблицы с использованием двоеточий `:`.
- `:` справа от тире для выравнивания по правому краю.
- `:` слева и справа от тире для выравнивания по центру.
- `:` слева от тире для выравнивания по левому краю.
```markdown
| Персонаж             | Актер                 | Роль                           |

| Элевен (11)          | Милли Бобби Браун     | Таинственная девочка с силами  |
```

В **Markdown**, форматирование текста внутри таблицы поддерживает использование различных элементов форматирования, таких как ссылки, код (слова или фразы в обратных кавычках `` ` `` только, не блоки кода), и выделение текста. Однако, есть ограничения на использование некоторых элементов форматирования внутри таблиц.

- Нельзя использовать заголовки внутри **Markdown** таблиц.
- Запрещено использование **Markdown** блоков цитат, списков, горизонтальных линий внутри таблиц. 
- Не все HTML-теги поддерживаются внутри **Markdown** таблиц.
