### 1.2. Работа с файловой системой

#### стурктура команды
```bash
command [options] [arguments]
```
command – имя команды.
[options] – опции или флаги, которые модифицируют поведение команд. Квадратные скобки говорят, что этот блок не обязателен и его можно пропустить.
[arguments] – аргументы команды, на которые направлено её действие
