### Hash индексы
Работают подобно хэш мапе в Go, где ключ - это значение индексируемого столбца. А значение - внутренний номер записи в таблице. получение значения по индексу происходит за константное время.
Работает только со сравнением **=**


### B-tree индексы
Представляет собой структуру `сбалансированноое дерево` 


Работает со сравнениями: **=**, **<**, **>**, **IN**, **BETWEEN**, **col LIKE 'foo%'**

### Правила использования индексов
Оптимизатор **проигнорирует** индекс, если:
1. Применяется функция к колонке в `WHERE`, а функционального индекса нет (например, `WHERE YEAR(date_col) = 2023` вместо `WHERE date_col >= '2023-01-01' AND date_col < '2024-01-01'`).
2. Тип данных в условии не совпадает с типом колонки (неявное преобразование типов убивает индекс).
3. Таблица очень маленькая (оптимизатор решит, что полное сканирование таблицы быстрее, чем чтение индекса + таблицы).
4. Вы ищете по `LIKE '%text%'` (B-Tree не работает, нужен полнотекстовый индекс). `LIKE 'text%'` — работает.


### Сравнительная таблица
| Тип индекса             | Oracle           | PostgreSQL          | Лучшее применение                                            |
| ----------------------- | ---------------- | ------------------- | ------------------------------------------------------------ |
| **B-Tree**              | ✅ (Default)     | ✅ (Default)        | Уникальные ID, даты, строки. Точечный поиск и диапазоны.     |
| **Bitmap**              | ✅               | ❌                  | OLAP, низкая кардинальность (статусы, флаги).                |
| **Function-Based**      | ✅               | ✅                  | Поиск по `UPPER()`, `LOWER()`, вычисляемым полям.            |
| **Reverse Key**         | ✅               | ❌                  | Равномерное распределение вставок по ID (OLTP).              |
| **GIN (Inverted)**      | ❌ (Есть Domain) | ✅                  | JSONB, массивы, полнотекстовый поиск.                        |
| **GiST**                | ❌ (Есть Domain) | ✅                  | Геометрия (PostGIS), диапазоны, полнотекст.                  |
| **BRIN**                | ❌               | ✅                  | Огромные таблицы с естественной сортировкой (логи, события). |
| **Partial (Частичный)** | ✅               | ✅                  | Индексация только подмножества строк (экономия места).       |
| **Text/Domain**         | ✅ (Oracle Text) | ✅ (через GIN/GiST) | Полнотекстовый поиск, гео-данные.                            |
