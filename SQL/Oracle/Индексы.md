
### B-Tree Index (Индекс по сбалансированному дереву)
Стандартный индекс для колонок с высокой кардинальностью (много уникальных значений).

```sql
-- Создание
CREATE INDEX idx_emp_id ON employees(employee_id);

-- Использование (поиск по точному совпадению или диапазону)
SELECT * FROM employees WHERE employee_id = 100;
SELECT * FROM employees WHERE employee_id BETWEEN 100 AND 200;
```


### Bitmap Index (Битовый индекс)
Идеален для колонок с **низкой кардинальностью** (мало уникальных значений, например, `status`, `gender`, `is_deleted`). Используется преимущественно в хранилищах данных (OLAP), а не в OLTP.
```sql
-- Создание
CREATE BITMAP INDEX idx_emp_status ON employees(status);

-- Использование (отлично работает с логическими операторами AND/OR)
SELECT * FROM employees WHERE status = 'ACTIVE' AND department_id = 10;
-- Oracle может объединять несколько битовых индексов на лету (Bitmap Index Scan)
```


### Function-Based Index (Функциональный индекс)
Индексирует не саму колонку, а результат вычисления функции или выражения.
```sql
-- Создание (индексируем имя в верхнем регистре)
CREATE INDEX idx_emp_upper_name ON employees(UPPER(last_name));

-- Использование (запрос ДОЛЖЕН точно повторять функцию из индекса)
SELECT * FROM employees WHERE UPPER(last_name) = 'IVANOV';
```


### Reverse Key Index (Индекс с реверсивным ключом)
Физически разворачивает байты ключа. Используется для решения проблем конкурентности при массовых последовательных вставках (например, по последовательности/ID).
```sql
-- Создание
CREATE INDEX idx_emp_seq ON employees(employee_id) REVERSE;

-- Использование (работает только для точного совпадения, НЕ работает для диапазонов!)
SELECT * FROM employees WHERE employee_id = 12345;
```


### Domain Index (Специализированные индексы)
Индексы для специфических типов данных: полнотекстовый поиск (Oracle Text), пространственные данные (Oracle Spatial), JSON.
```sql
-- Создание полнотекстового индекса (Oracle Text)
CREATE INDEX idx_emp_resume_text ON employees(resume) INDEXTYPE IS CTXSYS.CONTEXT;

-- Использование
SELECT * FROM employees WHERE CONTAINS(resume, 'Oracle AND PL/SQL') > 0;
```
