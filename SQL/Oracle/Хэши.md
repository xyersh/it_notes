
## Некриптографическое хэширование

**ORA_HASH(`expr [, max_bucket [, seed_value ] ]`) NUMBER**  - основная функция для некриптографического хэширования в Oracle DB.
Принимает параметры:
- **expr** - Данные, которые нужно захешировать. Ограничений по длине практически нет.
	- разрешенные типы выражения: `VARCHAR2`, `NUMBER`, `DATE`, `TIMESTAMP`, `RAW` и вложенные таблицы `NESTED TABLE`
	- запрещенные типы выражения: Типы больших объектов `LONG` и любые типы `LOB` (`CLOB`, `BLOB`, `NCLOB`), а также пользовательские типы объектов
- **max_bucket** - Задает верхнюю границу возвращаемого числа(от 0 до `max_bucket`). Принимает любое целое число от `0` до `4294967295` (максимум для 32 бит). **По умолчанию:** `4294967295`
- **seed_value** - Числовой аргумент (`NUMBER`). Позволяет получить другой хеш для одного и того же выражения. Принимает любое целое число от `0` до `4294967295`. **По умолчанию:** `0`


### Примеры использования 
```sql

-- 
SELECT ORA_HASH('Имя Пользователя') FROM dual;

-- Разделит всех клиентов на 5 групп (от 0 до 4) 
SELECT customer_id, ORA_HASH(customer_id, 4) as group_id FROM customers;


-- Случайный выбор данных (Семплирование)
SELECT * FROM huge_table WHERE ORA_HASH(id, 99) = 7;

-- Быстрое сравнение строк:** Вместо того чтобы сравнивать 10 больших 
-- текстовых колонок между двумя таблицами, можно сравнить их один числовой хеш:
FROM table1 t1 JOIN table2 t2 ON ORA_HASH(t1.col1 || t1.col2 || t1.col3) = ORA_HASH(t2.col1 || t2.col2 || t2.col3);
```



## Криптографическое хэширование

**STANDARD_HASH(`expr [, 'method']`) RAW** - применима для криптографического хэширования.
Принимает параметры:
- **expr** - Данные, которые нужно захешировать. Ограничений по длине практически нет.
	- разрешенные типы выражения: `VARCHAR2`, `NUMBER`, `DATE`, `TIMESTAMP`, `RAW` и вложенные таблицы `NESTED TABLE`
	- запрещенные типы выражения: Типы больших объектов `LONG` и любые типы `LOB` (`CLOB`, `BLOB`, `NCLOB`), а также пользовательские типы объектов
- **method** - наименование метода хэширования в виде строки (`'SHA1'`(по умолчанию), `'SHA256'`, `'SHA384'`, `'SHA512'`, `'MD5'`)


### Примеры использования
```sql
SELECT STANDARD_HASH('1111','SHA256') 
FROM dual;
```
