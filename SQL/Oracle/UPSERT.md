`MERGE` — это стандарт индустрии для задач ETL (Extract, Transform, Load) и синхронизации справочников. Он читается легче, чем связки `UPDATE` + `INSERT`, работает быстрее (один проход по таблицам вместо двух) и безопаснее с точки зрения транзакций.



```sql
MERGE INTO целевая_таблица  t
USING источник_данных (таблица, ИЛИ сложный запрос) s
ON (условие_связи)
WHEN MATCHED THEN  -- если если сопоставление строк в t и s найдено
    UPDATE SET ... -- Что делать, если запись нашлась
WHEN NOT MATCHED THEN -- в t НЕ найдена запись 
    INSERT (...) VALUES (...); -- Что делать, если записи не было
```


Основные положения:
- использование обоих блоков **WHEN** не обязательно. Любой из блоков можно опустить
- в качестве источника данных можно использовать не только таблицу, НО И запрос любой сложности 
- внутри блока **WHEN** можно использовать **WHERE**
	```sql
	WHEN MATCHED THEN 
    UPDATE SET t.salary = s.salary
    WHERE s.salary > t.salary; -- Обновляем ЗП только если в источнике она больше
	```
- внутри блока **WHEN MATCHED** можно использовать **DELETE**
