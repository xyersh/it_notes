
**VALIDATE_CONVERSION**

```sql
SELECT 
    date_string,
    VALIDATE_CONVERSION(date_string AS DATE, 'DD.MM.YYYY') AS is_valid
FROM (
    SELECT '25.12.2023' AS date_string FROM DUAL UNION ALL
    SELECT '31.02.2023' AS date_string FROM DUAL UNION ALL -- Неверная дата (в феврале 31 день)
    SELECT 'abc'       AS date_string FROM DUAL
);
```
