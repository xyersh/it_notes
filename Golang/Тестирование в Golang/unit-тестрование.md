

### Основные положения
- `testing` - стандартный пакет для тестирования кода
- `testing.T` - основной тип используемый при тестировании. Подробнее про данный тип смори ниже.
- Тестовые файлы должны иметь суффикс `_test.go`. Компилятор Go автоматически игнорирует их при сборке бинарника.
- Тестовые функции должны начинаться с префикса `Test` и принимать аргумент `*testing.T`:
	```go
	func TestAdd(t *testing.T) { ... }
	```
- Запуск тестов осуществляется командой `go test ./...` (рекурсивно по всем пакетам).
- В стандартном пакете нет макросов типа `assert` все проверки происходят явно при помощи **if**
- Можно проводить DTD

### testing.T
Данный тип передается в функции для тестирования
Используется для управления состояния теста а также для передачи тестовых логов
Тест заканчивается, когда:
- встречается `return`
- встречаются методы `T.FailNow`, `T.Fatal`, `T.Fatalf`, `T.SkipNow`, `T.Skip`, или `T.Skipf`. Данные методы вызываются в горутине, которая вызывает тестовую функцию.  

- `t.Helper()` - используется внутри функций-хэлперов
-  `t.Errorf()` — фиксирует ошибку, но тест продолжает выполняться.
- `t.Fatalf()` — фиксирует ошибку и **немедленно прерывает** выполнение теста (используйте, если дальнейшая проверка бессмысленна, например, при `nil` указателе).
- `t.Parallel()` - Запуск тестов в параллельном режиме. Данная функция вызывается как внутри самой тестовой функции, так и внутри функции, подаваемой параметром в **t.Run()**.
- `t.Run(name string, f func(*T)) bool` - запуск сабтеста в отдельной горутине.





### Табличные тесты (Table-Driven Tests)
Это **главный идиоматический прием** в Go. Вместо написания десяти функций `TestAdd1`, `TestAdd2`, мы создаем одну функцию с таблицей входных/выходных данных.
Данный подход реализуется:
- использованием массива структур с входными данными для тестирования 
- использованием функции `t.Run()`

TDT позволяет запускать одиночные подтесты из массива тестов
```go
go test -run TestAdd/zero ## запускает только кейс "zero"
```

### CLI-команды
#### Запуски тестов 
- Запуск тестов только в текущем пакете (директории).
```bash
go test
```
- Запуск тестов во всех пакетах текущего проекта (рекурсивно во всех поддиректориях).
```bash
go test ./...
```
- Запуск тестов в конкретной директории и всех её поддиректориях.
```bash
go test ./internal/service/...
```

- Подробный вывод: показывает имя каждого теста, его статус (`PASS`, `FAIL`, `SKIP`) и время выполнения. Полезно для отладки.
```bash
go test -v
```

- Флаг `-run` принимает регулярное выражение для выбора конкретных тестов (функций, начинающихся с `Test`).
```bash
go test -run TestMyFunction # Запуск только теста с именем `TestMyFunction`.
go test -run "TestUser|TestOrder" # Запуск тестов, содержащих `TestUser` или `TestOrder`.
go test -run TestParent/Child # Запуск конкретного подтеста (subtest) внутри родительского теста.
go test -run ^$ # Пропуск всех обычных тестов (часто используется вместе с бенчмарками).
```

- Запуск тестов с включенным детектором гонок (Race Detector).
```bash
go test -race
go test -race ./...
```


- Установка таймаута для выполнения тестов (по умолчанию 10 минут). Если тесты не завершатся за 30 секунд, процесс упадет с дампом.
```bash
go test -timeout 30s
```

- Ограничение количества одновременно выполняемых тестов, использующих `t.Parallel()` (по умолчанию равно количеству ядер CPU).
```bash
 go test -parallel 4
```

- Ограничение количества пакетов, которые компилируются и тестируются одновременно.
```bash
go test -p 2 ./...
```

- Полная очистка кэша тестов.
```bash
go clean -testcache
```


#### Покрытие кода тестированием
Показывает процент покрытия кода тестами для текущего пакета.
```bash
go test -cover
```

снять профиль покрытия тестами
```bash
go test ./math -coverprofile=coverage.out
```

открыть профиль
```bash
 go tool cover -html=coverage.out
```


ПРИМЕР
```go
func TestAdd(t *testing.T) {
    tests := []struct {
        name     string
        a, b     int
        expected int
    }{
        {"positive numbers", 2, 3, 5},
        {"negative numbers", -1, -1, -2},
        {"zero", 0, 5, 5},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            got := Add(tt.a, tt.b)
            if got != tt.expected {
                t.Errorf("got %d, want %d", got, tt.expected)
            }
        })
    }
}
```
